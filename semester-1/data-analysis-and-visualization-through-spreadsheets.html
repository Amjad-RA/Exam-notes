💡 What the two papers tell you
  • Both papers set the same 10-mark essay: “Discuss the key features of Pivot Tables and their importance, with an example.” Learn this answer first.
  • Two 6-mark questions repeated almost word for word: relative/absolute/mixed referencing and the Watch Window.
  • Nearly every question is a “how do you…” or “what is the difference…” question. Marks go to the menu path (Data ▸ Sort ▸ Add Level), a formula with its result, and a tiny example table.

The 10-minute exam cheat sheet

Every definition, menu path and function syntax that earns marks — scan this outside the hall.

MODULE ISpreadsheet basics & functions

  • Spreadsheet: an electronic grid of rows (1, 2, 3…) and columns (A, B, C…) for storing, calculating and analysing data. Workbook = file; worksheet = one sheet (tab). Excel: 1,048,576 rows × 16,384 columns (A to XFD).
  • Cell = intersection of a row and a column, named by its address (C5). Range = a group of adjacent cells (A1:D10).
  • Window: title bar · Quick Access Toolbar · Ribbon (tabs) · Name Box · Formula Bar · column/row headings · active cell · sheet tabs · status bar.
  • Insert/delete: right-click ▸ Insert / Delete (shift cells, entire row, entire column) · Home ▸ Cells ▸ Insert / Delete · Ctrl+Shift++ / Ctrl+-.
  • Referencing: relative A1 (changes when copied) · absolute $A$1 (fixed) · mixed $A1 / A$1. F4 cycles through them.
  • Link sheets: =Sheet2!B5 · other file: =[Sales.xlsx]Jan!$C$4.
  • Functions: =IF(B2>=40,"Pass","Fail") · =ROUND(3.146,2)→3.15 · =CEILING(23,5)→25 · =FLOOR(23,5)→20 · =COUNTIF(C2:C11,">=60") · =SUMIF(A:A,"East",C:C) · =VLOOKUP(value, table, col_index, FALSE).
  • Freeze Panes keeps headings visible while scrolling; Split makes up to 4 separately scrollable panes (View tab).

MODULE IIData cleansing

  • Data cleansing: detecting and correcting errors, duplicates, blanks and inconsistencies so the data is accurate and ready for analysis. “Garbage in, garbage out.”
  • Tools: Remove Duplicates · TRIM / PROPER / UPPER · Find & Replace · Text to Columns · Flash Fill · data validation · spell check.
  • Import: Data ▸ Get Data ▸ From Text/CSV / Web / Database ▸ Load or Transform (Power Query). Export: File ▸ Save As ▸ CSV / PDF.
  • Sort rearranges rows in order (A→Z, smallest→largest). Multiple columns: Data ▸ Sort ▸ Add Level. Filter hides rows that don't meet a condition (Data ▸ Filter, Ctrl+Shift+L).
  • Data validation: restricts what can be entered — Data ▸ Data Validation ▸ Allow (whole number, decimal, list, date, time, text length, custom) + input message + error alert (Stop, Warning, Information).
  • Remove duplicates: Data ▸ Remove Duplicates ▸ choose columns.
  • Group / Subtotal: Data ▸ Group (outline +/−); Data ▸ Subtotal — sort first, then “At each change in / Use function / Add subtotal to”.
  • Conditional formatting: Home ▸ Conditional Formatting ▸ Highlight Cells Rules (greater than, between, text contains, duplicate values) · Top/Bottom Rules (top 10, bottom 10%, above average).

MODULE IIIPivot tables & what-if analysis

  • Pivot table: an interactive tool that summarises large data — sum, count, average — by dragging fields into Rows, Columns, Values, Filters, without formulas or changing the source.
  • Create: click in the data ▸ Insert ▸ PivotTable ▸ choose range and location ▸ drag fields. Refresh after the source changes.
  • Features: summarise · group (dates, numbers) · sort and filter · slicers and timelines · Value Field Settings (Sum, Count, Average, % of total) · drill-down (double-click) · Pivot Chart.
  • What-If Analysis (Data ▸ What-If Analysis): Scenario Manager (several input sets), Goal Seek (one input to reach a target result), Data Table (one or two variables, many results).
  • Goal Seek: Set cell (formula) ▸ To value (target) ▸ By changing cell (input). It works backwards from the answer.
  • Watch Window: Formulas ▸ Formula Auditing ▸ Watch Window ▸ Add Watch. It shows Book, Sheet, Name, Cell, Value and Formula of chosen cells while you work elsewhere.
  • Formula auditing: Trace Precedents · Trace Dependents · Remove Arrows · Show Formulas (Ctrl+`) · Error Checking · Evaluate Formula · Watch Window.
  • Add-ins: File ▸ Options ▸ Add-ins ▸ Manage Excel Add-ins ▸ Go — Analysis ToolPak, Solver, Power Pivot.

MODULE IVData visualization

  • Chart: a graphical representation of data that shows trends, comparisons and proportions at a glance.
  • Create: select data ▸ Insert ▸ Charts (or Recommended Charts) ▸ choose type. Alt+F1 = chart on the same sheet; F11 = new chart sheet.
  • Types: Column/Bar — compare categories · Line — trends over time · Pie — parts of a whole (one series) · Area, Scatter (XY), Combo, Histogram.
  • Format: Chart Elements (+) — chart title, axis titles, legend, data labels, gridlines, data table · Chart Design ▸ Change Chart Type · Format pane for colours and styles.
  • Pivot Chart: select the pivot table ▸ PivotTable Analyze ▸ PivotChart. It is linked to the pivot table and has field buttons.
  • Dashboard: one screen combining KPIs, pivot charts, slicers and tables to give a global picture of the data.
  • Form controls (Developer ▸ Insert): combo box, list box, check box, option button, spin button, scroll bar, button. Format Control ▸ Cell link connects them to formulas.

Syntax you must write from memory

IF=IF(logical_test, value_if_true, value_if_false)
VLOOKUP=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
COUNTIF=COUNTIF(range, criteria)
SUMIF=SUMIF(range, criteria, [sum_range])
ROUND=ROUND(number, num_digits)
CEILING / FLOOR=CEILING(number, significance) · =FLOOR(number, significance)
AND / OR=AND(cond1, cond2…) · =OR(cond1, cond2…)

Memory hooks
  • “$ = stay” — the dollar sign freezes whatever follows it: $A freezes the column, $1 the row.
  • “RCVF” — pivot areas: Rows, Columns, Values, Filters.
  • “Sort shuffles, filter hides.”
  • “CEILING goes up, FLOOR goes down” — both to the nearest multiple of the significance.
