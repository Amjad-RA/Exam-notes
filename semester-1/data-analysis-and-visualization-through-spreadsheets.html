10-minute cheat sheet

Every definition, menu path and function syntax that earns marks — scan this outside the hall.

MODULE ISpreadsheet basics & functions

  • Spreadsheet: an electronic grid of rows (1, 2, 3…) and columns (A, B, C…) for storing, calculating and analysing data. Workbook = file; worksheet = one sheet (tab). Excel: 1,048,576 rows × 16,384 columns (A to XFD).
  • Cell = intersection of a row and a column, named by its address (C5). Range = a group of adjacent cells (A1:D10).
  • Window: title bar · Quick Access Toolbar · Ribbon (tabs) · Name Box · Formula Bar · column/row headings · active cell · sheet tabs · status bar.
  • Insert/delete: right-click ▸ Insert / Delete (shift cells, entire row, entire column) · Home ▸ Cells ▸ Insert / Delete · Ctrl+Shift++ / Ctrl+-.
  • Referencing: relative A1 (changes when copied) · absolute $A$1 (fixed) · mixed $A1 / A$1. F4 cycles through them.
  • Link sheets: =Sheet2!B5 · other file: =[Sales.xlsx]Jan!$C$4.
  • Functions: =IF(B2>=40,"Pass","Fail") · =ROUND(3.146,2)→3.15 · =CEILING(23,5)→25 · =FLOOR(23,5)→20 · =COUNTIF(C2:C11,">=60") · =SUMIF(A:A,"East",C:C) · =VLOOKUP(value, table, col_index, FALSE).
  • Freeze Panes keeps headings visible while scrolling; Split makes up to 4 separately scrollable panes (View tab).

MODULE IIData cleansing

  • Data cleansing: detecting and correcting errors, duplicates, blanks and inconsistencies so the data is accurate and ready for analysis. “Garbage in, garbage out.”
  • Tools: Remove Duplicates · TRIM / PROPER / UPPER · Find & Replace · Text to Columns · Flash Fill · data validation · spell check.
  • Import: Data ▸ Get Data ▸ From Text/CSV / Web / Database ▸ Load or Transform (Power Query). Export: File ▸ Save As ▸ CSV / PDF.
  • Sort rearranges rows in order (A→Z, smallest→largest). Multiple columns: Data ▸ Sort ▸ Add Level. Filter hides rows that don't meet a condition (Data ▸ Filter, Ctrl+Shift+L).
  • Data validation: restricts what can be entered — Data ▸ Data Validation ▸ Allow (whole number, decimal, list, date, time, text length, custom) + input message + error alert (Stop, Warning, Information).
  • Remove duplicates: Data ▸ Remove Duplicates ▸ choose columns.
  • Group / Subtotal: Data ▸ Group (outline +/−); Data ▸ Subtotal — sort first, then “At each change in / Use function / Add subtotal to”.
  • Conditional formatting: Home ▸ Conditional Formatting ▸ Highlight Cells Rules (greater than, between, text contains, duplicate values) · Top/Bottom Rules (top 10, bottom 10%, above average).

MODULE IIIPivot tables & what-if analysis

  • Pivot table: an interactive tool that summarises large data — sum, count, average — by dragging fields into Rows, Columns, Values, Filters, without formulas or changing the source.
  • Create: click in the data ▸ Insert ▸ PivotTable ▸ choose range and location ▸ drag fields. Refresh after the source changes.
  • Features: summarise · group (dates, numbers) · sort and filter · slicers and timelines · Value Field Settings (Sum, Count, Average, % of total) · drill-down (double-click) · Pivot Chart.
  • What-If Analysis (Data ▸ What-If Analysis): Scenario Manager (several input sets), Goal Seek (one input to reach a target result), Data Table (one or two variables, many results).
  • Goal Seek: Set cell (formula) ▸ To value (target) ▸ By changing cell (input). It works backwards from the answer.
  • Watch Window: Formulas ▸ Formula Auditing ▸ Watch Window ▸ Add Watch. It shows Book, Sheet, Name, Cell, Value and Formula of chosen cells while you work elsewhere.
  • Formula auditing: Trace Precedents · Trace Dependents · Remove Arrows · Show Formulas (Ctrl+`) · Error Checking · Evaluate Formula · Watch Window.
  • Add-ins: File ▸ Options ▸ Add-ins ▸ Manage Excel Add-ins ▸ Go — Analysis ToolPak, Solver, Power Pivot.

MODULE IVData visualization

  • Chart: a graphical representation of data that shows trends, comparisons and proportions at a glance.
  • Create: select data ▸ Insert ▸ Charts (or Recommended Charts) ▸ choose type. Alt+F1 = chart on the same sheet; F11 = new chart sheet.
  • Types: Column/Bar — compare categories · Line — trends over time · Pie — parts of a whole (one series) · Area, Scatter (XY), Combo, Histogram.
  • Format: Chart Elements (+) — chart title, axis titles, legend, data labels, gridlines, data table · Chart Design ▸ Change Chart Type · Format pane for colours and styles.
  • Pivot Chart: select the pivot table ▸ PivotTable Analyze ▸ PivotChart. It is linked to the pivot table and has field buttons.
  • Dashboard: one screen combining KPIs, pivot charts, slicers and tables to give a global picture of the data.
  • Form controls (Developer ▸ Insert): combo box, list box, check box, option button, spin button, scroll bar, button. Format Control ▸ Cell link connects them to formulas.

“A spreadsheet is an electronic worksheet made of rows and columns of cells, used to store, organise, calculate and analyse data with formulas and functions, which recalculate automatically when the data changes.”

1.4Relative, absolute and mixed referencing

A cell reference tells a formula where to find its data. When a formula is copied, Excel adjusts the references. The $ sign stops the adjustment for the column, the row, or both. Press F4 while editing to cycle A1 → $A$1 → A$1 → $A1.

1.5Linking data between worksheets and workbooks

Linking means a cell in one sheet uses the value of a cell in another sheet or workbook through a formula, so the data is entered once and updates automatically everywhere it is used.

How to link
  1. In the destination cell type =
  2. Click the source sheet tab, click the source cell, press Enter
  3. Excel writes =Jan!B5; with spaces in the name: ='Jan Sales'!B5
  4. Another workbook: =[Sales.xlsx]Jan!$B$5
  5. 3-D sum across sheets: =SUM(Jan:Mar!B5)
  6. Or Copy ▸ Paste Special ▸ Paste Link
Uses and common issues
  • Uses: summary sheet from monthly sheets; one master price list; consolidation of branch reports; dashboards.
  • Broken links when the source file is moved or renamed — fix via Data ▸ Edit Links / Workbook Links ▸ Change Source.
  • #REF! error when the source sheet or cell is deleted.
  • Update prompts and security warnings when opening linked files.
  • Circular references, slower recalculation, and hard-to-trace errors in long chains.

CEILING vs FLOOR — the pair examiners likeBoth round to a multiple of the significance. CEILING always rounds up (away from zero for positive numbers), FLOOR always down: =CEILING(4.3,1) → 5, =FLOOR(4.7,1) → 4; =CEILING(23,5) → 25, =FLOOR(23,5) → 20. ROUND goes to the nearest value. Excel's names are CEILING and FLOOR (also CEILING.MATH, FLOOR.MATH); “CEIL” in the syllabus means CEILING. In Google Sheets the significance is optional and defaults to 1.
VLOOKUP limitationsSearches only the leftmost column and returns values to its right; the column index breaks if columns are inserted; returns #N/A when not found (wrap in IFERROR). HLOOKUP does the same along rows. Newer Excel has XLOOKUP, which removes these limits.

3.3What-If Analysis and Goal Seek

What-If Analysis means changing the values in cells to see how the changes affect the results of formulas. Path: Data ▸ Forecast ▸ What-If Analysis. It has three tools:

Scenario Manager

Saves several sets of input values (best case, worst case, likely case) and switches between them or makes a summary report.

Goal Seek

Compare / explain the difference between relative, absolute and mixed cell referencing in Excel with examples.›6 marks★ Asked 2×

Asked in: Univ 2024 Q11 · Amal 2025 Q11

A cell reference identifies the cell a formula uses. When a formula is copied, Excel adjusts the references; the $ sign controls which part is fixed. F4 cycles A1 → $A$1 → A$1 → $A1.

1. Relative reference (A1)

Both row and column change relative to the new position. In D2, =B2*C2 (Qty × Rate) copied to D3 becomes =B3*C3. Used when the same calculation repeats down a column.

2. Absolute reference ($A$1)

Neither row nor column changes. GST rate 18% is in F1: in E2 =D2*$F$1; copied to E3 → =D3*$F$1. Without $, E3 would refer to F2 (blank) and give 0. Used for constants — tax rate, exchange rate.

3. Mixed reference ($A1 or A$1)

Only one part is fixed. $A1 fixes the column; A$1 fixes the row. Multiplication table: in B2 =$A2*B$1, filled across and down, always multiplies column A by row 1.

Mixed (column fixed)=$A1=$A2
Mixed (row fixed)=A$1=B$1

Choosing the right reference lets one formula be copied across a whole table without errors.

=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup]). Searches the first column top to bottom. =VLOOKUP(103,A2:D6,3,FALSE) finds roll no. 103 and returns column 3 (Marks) → 62. (Draw the highlighted grid from Module I, 1.6.)

HLOOKUP (horizontal)

=HLOOKUP(lookup_value, table_array, row_index_num, [range_lookup]). Searches the first row left to right. With months in row 1 and sales in row 2: =HLOOKUP("Mar",A1:L2,2,FALSE) returns March sales.

Points to remember
  • FALSE = exact match (use for codes, names); TRUE = approximate match on sorted data (grade slabs).
  • Returns #N/A if not found — wrap in IFERROR(…,"Not found").
  • Lookup column must be leftmost (VLOOKUP) / top row (HLOOKUP); newer Excel has XLOOKUP.

Lookups connect tables — price lists, mark lists, employee records — without manual searching.

Explain Group, Ungroup and Subtotal in Excel.›6 marksLikely · not yet asked

These outline tools organise large lists so detail can be collapsed or expanded and group totals calculated automatically.

  2. An outline bar with − (collapse) and + (expand) appears.
  3. Ungroup: select ▸ Data ▸ Ungroup (Shift+Alt+←).
Subtotal
  1. Sort the data by the grouping column (e.g., Region).
  2. Data ▸ Outline ▸ Subtotal.

Explain the What-If Analysis tools: Scenario Manager, Goal Seek and Data Table.›6 marksLikely · not yet asked

What-If Analysis (Data ▸ What-If Analysis) changes input values to see their effect on formula results.

  1. Scenario Manager — stores named sets of inputs (best, worst, likely case); Show switches between them; Summary compares results side by side.
  2. Goal Seek — finds the one input needed to reach a target result: Set cell (formula) ▸ To value ▸ By changing cell. Example: Test 3 mark needed for a 75 average → 87.
  3. Data Table — shows results for many values of one or two inputs at once; e.g., EMI for interest rates 8–12% and periods 5–20 years.

These tools support planning and decision-making by testing “what happens if…?” before acting.

Explain the process of linking data between multiple worksheets, its uses, and common issues that may arise.›10 marks

Asked in: Univ 2024 Q16

Linking means using a formula in one worksheet (or workbook) that refers to a cell in another, so data entered once flows automatically to every place it is used, and updates when the source changes.

A. Process of linking
  1. Same workbook: in the destination cell type =, click the source sheet tab, click the source cell, press Enter. Excel writes =Jan!B5; with spaces: ='Jan Sales'!B5.
  2. Calculations across sheets: =Jan!B5+Feb!B5+Mar!B5, or a 3-D reference =SUM(Jan:Mar!B5).
  3. Another workbook: open both files and click the source: =[Sales.xlsx]Jan!$B$5; when closed, the full path is shown.
  4. Paste Link: copy the source ▸ destination ▸ Home ▸ Paste ▸ Paste Special ▸ Paste Link.
  5. Manage links: Data ▸ Queries & Connections ▸ Edit Links (Workbook Links) — Update Values, Change Source, Break Link.

2January=Jan!B20 → 48,500
3February=Feb!B20 → 51,200

A Summary sheet linked to monthly sheets.
B. Uses
  • Consolidation — monthly or branch sheets into one summary.
  • Single source of truth — one master price or rate list used everywhere.
  • Automatic updates — change once, all reports update; saves time, avoids re-typing errors.
  • Dashboards and reports fed from data sheets; separates input and output.
C. Common issues
  • Broken links — the source file is moved, renamed or deleted (fix with Change Source).
  • #REF! errors — a referenced sheet, row or cell is deleted.
  • Security warnings and update prompts when opening files with external links.
  • Outdated values if links are not refreshed; circular references.
  • Hard to trace long chains of links; slower recalculation in big workbooks.
  • Sharing problems — others may not have access to the source file path.

Linking makes multi-sheet workbooks consistent and efficient, provided links are documented, kept in stable locations and checked with Edit Links and formula auditing tools.

(A) Explain the importance of data cleansing in Excel with suitable examples. (5 marks) (B) Describe how sorting and filtering help in organising and analysing data effectively, with examples. (5 marks)›10 marks

Asked in: Amal 2025 Q17

(A) Importance of data cleansing

Data cleansing is detecting and correcting errors, duplicates, blanks and inconsistencies so that data is accurate and ready for analysis — “garbage in, garbage out”.

  1. Accuracy: duplicate rows double-count sales; Data ▸ Remove Duplicates fixes totals.
  2. Consistency: “Calicut”, “Kozhikode”, “kozhikode ” become one value with Find & Replace, =TRIM() and =PROPER() — otherwise a pivot shows three cities.
  3. Correct data types: numbers stored as text break SUM; dates in mixed formats break sorting — use Text to Columns / Number format.
  4. Completeness: find blanks (Go To Special ▸ Blanks) and fill or flag them.
  5. Prevention: data validation stops wrong entries (marks > 100).
  6. Reliable decisions and efficiency: clean data makes formulas, pivots and charts correct the first time.
(B) Sorting and filtering

Sorting rearranges rows in order; filtering shows only rows meeting conditions and hides the rest.

  1. Sorting organises: Data ▸ Sort — Marks largest to smallest gives the rank list instantly; names A to Z for registers.
  2. Multi-level sort: Department A→Z, then Salary largest first (Add Level) — groups and ranks together.
  3. Filtering focuses: Data ▸ Filter — show only “Sales” department, only marks below 40, top 10 values, dates in March.
  4. Analysis: filtered data works with SUBTOTAL and the status bar to total only visible rows; Advanced Filter extracts records to another place.
  5. Prepares data for Subtotal (needs sorted data), spotting duplicates and outliers, and reports.

Cleansing makes the data trustworthy; sorting and filtering make it readable and focused — together they are the first steps of any spreadsheet analysis.
